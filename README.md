# База TG-контактов — брони и ремонты

Одностраничный инструмент для холодных сообщений в Telegram: карточки контактов, 16 готовых сообщений, 61 поисковый запрос и учёт статусов.

**Один файл:** `index.html`. Ни сборки, ни зависимостей, ни сервера — открывается двойным кликом.

## Что внутри

- **Контакты** — фильтры по нише, городу, статусу и тексту; на карточке кнопки «Написать в TG», «Сообщение», «Изменить».
- **Сообщения** — 16 текстов: 8 для брони (салоны, барбершопы, мастера) и 8 для ремонтов под ключ. Плейсхолдеры подставляются из карточки контакта.
- **Поиск контактов** — готовые запросы `site:t.me` по 5 городам плюс Instagram, 2GIS, OLX.
- **Как писать** — лимиты Telegram, порядок работы, легенда статусов.
- **Массовое добавление** — строки вида `Название | @ник | город | район | хук`.
- **Экспорт/Импорт JSON** — бэкап и перенос между устройствами.

## Данные

Всё хранится в браузере (`localStorage`), ничего не отправляется на сервер. На новом устройстве база начинается со стартовых контактов — перенести остальное: «Экспорт» → файл JSON → «Импорт» на другом устройстве.

## Хостинг

Файл самодостаточный, поэтому подойдёт любой статический хостинг (GitHub Pages, Netlify, Vercel). Важно: на хостинге база у каждого браузера своя, данные не синхронизируются между устройствами.
